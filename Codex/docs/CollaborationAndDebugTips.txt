## How to Log
- Keep a single block per topic or feature.
- To expand an existing topic, update its block instead of creating a new one.
- Append commit hashes or PR numbers to the **Related Commits/PRs** line as work continues.
- Use `Codex/tools/add-tip.ps1` with the same `-Topic` value to generate a block, then merge it into the existing entry.
- Always record environment limitations (for example, missing Windows desktop support for WPF builds).
- When Windows collaborators run builds, capture the commands and summarize their results so Codex can reference them.
