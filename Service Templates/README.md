# Service Templates

This directory consolidates the reference assets that demonstrate how built-in services are presented in the UI. The files are grouped by protocol so designers and developers can reuse the mockups when iterating on similar experiences or building new services.

## Inventory

1. **MQTT mockups**
   - `Chappie MQTT-Create-Window.xml` & `Chappie-MQTT-Create-Window.svg` – draw.io source and SVG export of the MQTT create dialog.
   - `Chappie MQTT-Edit-Connection.xml` & `Chappie MQTT-Edit-Connection.svg` – create/edit connection workflow reference.
   - `Chappie MQTT-Tag-Subscriptions.xml` & `Chappie-MQTT-Tag-Subscriptions.svg` – subscription editor layout.

2. **TCP mockups**
   - `TCP-Create-Service.xml` & `Chappie-TCP-Create-Service.svg` – TCP service creation window.
   - `TCP-Service-Messages.xml` & `Chappie-TCP-Service-Messages.svg` – sample message management layout.

3. **Application shell layouts**
   - `DesktopTemplateLayout.xml` – overall shell mockup exported from draw.io.
   - `MainWindow-Design.layout.json` – layout data saved from the Blend designer.

Use these examples as a starting point for future templates. Store new protocol-specific assets in a dedicated subfolder (for example, `Service Templates/Serial`) so the collection stays organized.
